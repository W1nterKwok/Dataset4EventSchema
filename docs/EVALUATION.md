# 评测使用约定

| 资源类型 | 可用指标 | 必须固定的条件 |
| --- | --- | --- |
| 关系抽取 | Precision、Recall、Micro-F1 | 事件对、关系方向、匹配单位、文档划分 |
| 模式归纳 | Event F1、Temporal/Hierarchical Relation F1 | 语义匹配编码器、节点匹配规则、场景留出 |
| 图事件预测 | MRR、Hit@k | 候选集、负例、官方划分、图构建版本 |
| EV² | CEC/CRR Accuracy | S/I四任务分项、关系类型 |
| 关系集合预测 | 按查询Macro P/R/F1 | 预测截点、新闻时间过滤、CAMEO标签映射 |
| 具体时间预测 | RMSE、MAE | 单位、预测跨度、观察窗口 |
| 开放式预测 | Accuracy、Completeness等 | 官方定义、裁判版本、人工核验 |
| RESPONSE | 自动文本相似性指标与分时限人评 | immediate/week/month、答案和解释分别评价 |

原始文档、主题、场景或完整案例应跨划分隔离。规则库构建、检索器训练和增强样本生成都不得使用测试答案。预测后揭示结果，再更新知识库；时间截断只能约束外部证据，不能保证模型没有历史记忆。

RESPONSE的人类参考回答不是唯一正确方案，也不是现实应急建议。自动文本相似分数不能单独解释为危机应对可靠性。
