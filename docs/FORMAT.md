# 示例格式和字段注释

所有示例采用合法UTF-8 JSON。JSON不支持行内注释，因此注释放在 `_说明.字段注释` 中，实际数据放在 `record` 中。

`_说明.kind` 只有两种值：

- `upstream_record`：作者原始记录，附原文件位置、版本或提交及许可。
- `illustrative_template`：自行编写的教学样本，未声称使用作者原始字段；只用于理解该数据集任务。

当前真实样例：ODIN完整模式、OpenEP配对问答。其余均明确标为自编模板，下载真实数据后应单独编写原始格式解析，不能直接把模板当作官方schema。

原始数据不强制转换为同一种图格式：部分有序脚本、因果图选择题、二元抽象规则、开放式预测、危机场景问答属于不同任务。字段、关系方向、答案编号及时间单位均需按原始版本映射。
